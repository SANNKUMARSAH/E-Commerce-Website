# 🛒 E-Commerce Website

A full-stack e-commerce web application built using HTML, CSS, JavaScript, Node.js, Express.js, MongoDB, and JWT authentication.

## 🚀 Features

### Frontend
- Home page
- Product listing
- Product details
- Product search
- Categories
- User Login & Signup
- Shopping Cart
- Wishlist
- Checkout
- My Orders
- Responsive design

### Backend
- REST API with Express.js
- MongoDB database
- User authentication
- JWT authorization
- Password hashing
- Product management
- Cart management
- Wishlist management
- Order management
- Order cancellation

## 🛠️ Technologies Used

### Frontend
- HTML5
- CSS3
- JavaScript

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcryptjs
- CORS
